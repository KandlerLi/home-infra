# Home Infrastructure

Ansible configuration for a Debian home server and its services: base system,
storage, Docker, Nextcloud AIO, ingress, monitoring, and the KVM/libvirt host
for the k3s cluster. Each role documents itself in
`ansible/roles/<name>/README.md`.
