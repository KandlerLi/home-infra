# wireguard

Opt-in (`wireguard_enabled`, default `false`) WireGuard VPN server on
the homeserver, for admin access from outside the LAN: SSH, Nextcloud
AIO's `:8080`, `kubectl`, Prometheus. The public web services stay on
Traefik + Authelia and don't need it. See ADR 0024
(`docs/home-infra-docs`) for why WireGuard on the homeserver rather
than the FRITZ!Box's own VPN or Tailscale.

- **Endpoint**: `vpn.jkandler.de:51820/udp` (`aws/dyndns` CNAME to the
  DynDNS A record, IPv4 only). The FRITZ!Box forwards UDP 51820 to the
  homeserver's LAN IP -- a manual router setting, like 80/443/25.
- **Subnet** `10.13.13.0/24`, server `10.13.13.1`. Client traffic is
  masqueraded as the homeserver, so no return routes are needed on the
  FRITZ!Box or in the k3s VM.
- **Server key** is generated on the host (`/etc/wireguard/wg0.key`)
  and never leaves it; each apply prints the public key. A rebuilt host
  gets a new key, so update every client then.
- **Peers** (`wireguard_peers` in inventory) hold only public keys --
  generate the key pair in the client's WireGuard app.

## Adding a client

1. In the WireGuard app, create an empty tunnel; it generates a key
   pair. Copy its public key.
2. Add an entry to `wireguard_peers` in
   `ansible/inventory/group_vars/all/main.yml` with the next free
   `/32` address, and apply `site.yml` (peer changes are reloaded
   without dropping live tunnels).
3. Finish the client config:

   ```ini
   [Interface]
   PrivateKey = <generated by the app>
   Address = 10.13.13.2/32
   DNS = 192.168.178.100

   [Peer]
   PublicKey = <server public key from the apply output>
   Endpoint = vpn.jkandler.de:51820
   AllowedIPs = 10.13.13.0/24, 192.168.178.0/24, 192.168.101.0/24
   PersistentKeepalive = 25
   ```

   `AllowedIPs` above is a split tunnel (only home traffic goes through
   it); `0.0.0.0/0` sends everything through home instead. `DNS` points
   at Blocky, so ad-blocking applies on the road too.

## Checking it

```bash
sudo wg show            # on the homeserver: peers, latest handshake
ssh julian@192.168.178.100   # from the client, VPN on, off the LAN
```
